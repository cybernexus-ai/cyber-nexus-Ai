### 🚀 What is CYBER NEXUS MD?
A powerful, clean, non-encrypted WhatsApp Multi-Device bot built with Baileys. Fast, secure, and 100% customizable.

### ✨ Features
- ✅ Clean Code - No Encryption
- ✅ QR & Pairing Code Support
- ✅ Cyber Menu (eCitizen, KRA, CV, Posters)
- ✅ 24/7 Online (Render Deploy)
- ✅ Light & Fast

### 📦 Deploy Now

#### 1. Fork This Repo
Click Fork button top right.

#### 2. Deploy on Render
[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com)

- Build Command: `npm install`
- Start Command: `npm start`

#### 3. Scan QR
Check Render Logs > Scan QR with WhatsApp Linked Devices.

### 💻 How to Use
Type in WhatsApp:
- `menu` - Show main menu
- `hi` - Start bot
